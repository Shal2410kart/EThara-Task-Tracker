# Ethara Team Task Manager (MVP)

A Full-Stack role-based task management application built for the Ethara.AI assessment. 

**Live Demo:** [Paste your Railway URL here]
**Demo Video:** [Paste your Loom URL here]

### Tech Stack
* **Backend:** Python, Flask
* **Database:** PostgreSQL (Hosted via Railway), SQLAlchemy
* **Frontend:** HTML, Jinja2 Templates

### Core Features Completed
* **Authentication:** Login system.
* **Role-Based Access Control (RBAC):** Distinct views and permissions for 'Admin' vs 'Member' roles.
* **Task Management:** Admins can create and assign tasks; Members can view their assigned tasks.
* **Live Deployment:** Fully hosted and functional on Railway.

*Note: This MVP was developed manually within a strict timeframe to ensure 100% human-written, original code, prioritizing core database relationships and functional requirements over advanced UI styling.*
